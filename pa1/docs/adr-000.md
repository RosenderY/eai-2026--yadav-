# ADR-000 — Read the Baltic fixed-width export

## Context

The supplier writes single-byte Windows-1257 orders and a separate UTF-8 customer master. The sixth sample order ends inside the name field.

## Decision

Decode each file independently. Slice the 77-character line by its contractual offsets. Keep a rejected row with its original number. Replace the comma in the amount while preserving its scale.

## Alternatives considered

A whitespace split would separate parts of a name. An upstream versioned JSON export would remove the offset dependency but needs supplier cooperation.

## Consequences

A refund keeps its sign, and one truncated row leaves the remaining batch usable. A layout change of the same total width could still shift fields silently.
