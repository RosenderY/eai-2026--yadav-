# AI assistance and verification

AI assistance was used to help draft parts of the OpenAPI contract, TypeScript coordinator and explanatory documentation. The downstream mock-service code and public test harness are based on the official course scaffold.

Before submission, the student should read and understand the implementation, run the Spectral lint command, start the Compose stack, execute the public tests and inspect the resulting saga/idempotency files. No claim is made here that Docker or the public tests have already been executed in the target environment.
