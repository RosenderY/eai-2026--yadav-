## Where your work goes

In **your** repository (`eai-2026-<surname>`), in `capstone/` — not in `pa8/`.
Copy the whole `capstone/` folder from this repository into yours, then copy
your PA4–PA7 code into it and change it there.

Start with the brief: [`../capstone/README.md`](../capstone/README.md). Its §2
says where to begin, and §5.3 lists what grading replaces.
